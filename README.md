# 🏭 Информационный портал АСУТП

Веб-платформа для специалистов в области автоматизации технологических процессов (АСУТП). Проект представляет собой тематический новостной портал с системой публикации статей, форумом для профессионального обсуждения, инструментами аналитики, правилами сообщества и личным кабинетом пользователя.

---

## 🌟 Основные возможности

* **Лента новостей и статей** — публикация, просмотр и пагинация материалов по тематике автоматизации.
* **Профессиональный форум** — выделенная ветка для обсуждения инженерных вопросов с модулем правил (`forum_rules`).
* **Раздел FAQ** — страница с ответами на часто задаваемые вопросы пользователей.
* **Система авторизации** — полноценный вход (`login`), выход (`logout`) и разграничение прав доступа.
* **Закладки и Избранное** — возможность авторизованным пользователям сохранять статьи (`saved_articles`) для быстрого доступа.
* **Поиск и фильтрация** — полнотекстовый поиск по материалам сайта.
* **Гибкая сортировка** — сортировка контента по дате публикации, автору, названию и тегам.
* **Административная панель** — создание публикаций суперпользователями прямо из интерфейса.
* **Генерация отчетов** — экспорт данных в формат CSV и визуализация аналитики (модуль статистики).

---

## 🛠️ Стек технологий

* **Backend:** Python, Django (MTV)
* **Frontend:** HTML5, Django Template Language (DTL), Bootstrap 5.3 (Стили и адаптивная сетка), Bootstrap Icons
* **База данных:** SQLite / PostgreSQL

---

## 📂 Структура статических файлов и шаблонов

Проект использует модульную структуру шаблонов Django наследуемых от единой базы:
* `base.html` — главный каркас приложения. Содержит адаптивную навигационную панель (Navbar) со встроенным логотипом контроллера (`img/plc.png`), глобальные ссылки и логику отображения профиля пользователя.
* Стили проекта вынесены в отдельный статический файл: `static/articles/css/style.css`.

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd название-репозитория
```

### 2. Создание и активация виртуального окружения
```bash
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для Linux/macOS:
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Применение миграций базы данных
```bash
python manage.py migrate
```

### 5. Создание учетной записи администратора (Суперпользователя)
*Необходимо для добавления статей и доступа к скрытым панелям управления.*
```bash
python manage.py createsuperuser
```

### 6. Запуск сервера разработки
```bash
python manage.py runserver
```

После этого откройте браузер и перейдите по адресу: `http://127.0.0`
